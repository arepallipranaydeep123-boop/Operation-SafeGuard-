---

# Project Overview

Operation SafeGuard is an end-to-end Fraud Detection and Risk Monitoring System developed using SQL, Python, Machine Learning, and Power BI.

The project focuses on identifying suspicious financial transactions, detecting anomalies, and providing business intelligence dashboards for fraud monitoring.

---

# Problem Statement

Financial institutions process millions of transactions daily. Detecting fraudulent activities manually is difficult, time-consuming, and prone to errors.

The objective of this project is to automate fraud detection and identify high-risk transactions using machine learning and anomaly detection techniques.
